MOTION TEXT LAB / ABOUT

文字動畫素材庫

這是一個可直接拿來用的文字動畫素材庫，收錄 01–40 種文字動態。適合剪片片頭、社群短片、字幕與轉場；可以先在 Playground 預覽，再下載單一 HTML，或把效果規格交給 Agent 生成與整合。

可交付素材01 — 40
使用方式QUICK START

輸入文字 → 選效果 → 調速度。需要交給 Agent 時，按複製圖示，把 Prompt 直接貼給 Agent；要交付素材則下載 HTML。

左右箭頭切換效果 · Replay 重播 · 下載只含文字與特效
Agent 串接MACHINE READABLE

GET ./effects.json 讀取 01–40；用 effects[].order 找編號，再用 effects[].id 呼叫。

./index.html?effect={effect_id}&text={text}&speed={speed}#playground例如：02 → laser；也可使用 window.MotionTextLab.selectEffect(effect_id)。
